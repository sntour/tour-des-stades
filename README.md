# Tour Des Stades
Projet d'actualité des sports au Sénégal et le reste du monde.

Technologie utilisées:
* Java 11
* Spring Boot
* HATEAOS
* PostgreSQL
* FireBase
* Flyway
* [ReactJs](https://github.com/sntour/tour-des-stades-front.git)
* [React Native](https://github.com/sntour/tour-des-stades-mobile.git)
